## APK Audit 0.2.1

### Cài đặt
1. Tải **`apk-audit-0.2.1.zip`** bên dưới, giải nén vào một thư mục cố định.
2. Mở `installer/`, bấm đúp file theo máy: `Cai-dat-Windows.bat` · `Cai-dat-macOS.command` · `cai-dat-linux.sh`.
3. Tool tạo biểu tượng **APK Audit** trên màn hình chính và mở web. Vào **Thiết lập máy** để cài Java, JADX và AI CLI.

Đã cài bản cũ (0.1.0)? Cài lại một lần bằng ZIP này; từ bản này trở đi chỉ cần bấm **Cập nhật** trên web.

### Có gì mới
- **Cài một chạm:** script cài cho Windows / macOS / Linux, biểu tượng có logo trên màn hình chính.
- **Thiết lập máy:** kiểm tra và cài Java, JADX, Node, Claude CLI, Codex CLI bằng nút bấm, không cần quyền quản trị; nút đăng nhập AI.
- **Tự cập nhật:** web báo khi có bản mới, bấm **Cập nhật** là tool tự tải, cài và khởi động lại (giữ kết quả cũ).
- **Giao diện mới:** nền tối, font Nunito, thanh tab Kiểm tra / Lịch sử / Kết quả / Thiết lập máy.
- **Tự chọn model AI:** Claude Sonnet mới nhất hoặc Codex Sol mới nhất (mức low); không còn lỗi khi model cũ bị ngừng.
- **Rule mới:** mạng mediation phải đủ adapter và SDK (không tốn token). Bộ luật 0.12.0, 18 rule.
- **Xuất cho tester:** Copy cho Google Sheet theo mẫu bảng bug đối tác và Copy tóm tắt gửi đối tác.
